# 课程统一数据集

| 文件 | 用途 |
|---|---|
| books.json | 图书馆月度借阅：12个月×6品类，字段与讲义六案例代码完全一致（title/months/series[].category/counts） |
| studyrooms.json | 校园自习室：name/building/floor/seats/occupied/status/hours |
| empty.json | 空数据结构，用于演示"暂无数据"状态 |

数据为教学演示虚构数据，非真实统计；使用时页面须标注"数据来源：课程统一数据集"。
教师调整数据时**只改数值，不改字段名**，保证全部案例代码零修改兼容。
